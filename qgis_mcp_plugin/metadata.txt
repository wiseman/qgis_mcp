about=WAI QGIS MCP lets trusted AI assistants inspect projects, manage layers, run Processing algorithms, render maps, and execute PyQGIS code. Setup: open Plugins > WAI QGIS MCP and click Start Server. For Codex or the ChatGPT desktop app, install Node.js 18 or later, run "codex mcp add qgis -- npx -y qgis-mcp" in a terminal, then restart the assistant. For Claude Desktop, download the MCPB asset from the latest GitHub release and install it from Settings > Extensions > Advanced settings > Install Extension. For Claude Code, install Node.js 18 or later, run "/plugin marketplace add wiseman/qgis_mcp" followed by "/plugin install qgis-mcp@qgis-mcp", then run "/reload-plugins". Keep QGIS running while using the assistant. Only connect assistants you trust. See the homepage for complete setup and troubleshooting.
